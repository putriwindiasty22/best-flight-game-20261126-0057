**Ember Valley Run** — fly the Kestrel, a little single-prop valley runner, down the Ember Valley: thread eight glowing sky rings over ridges, river and a lakeside town, mind your fuel, then slow down and land gentle on the runway strip. Keyboard and mouse, no build step, no network — just open `game/index.html` in a desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` directly from any static server.

## Controls

- **↑ / ↓ or W / S** — pitch up / down
- **← / → or A / D** — bank left / right (turns the heading)
- **Shift** — throttle up, **Ctrl** — throttle down
- **Space** — airbrake
- **Mouse** — steer: pointer height sets pitch, pointer left/right sets bank
- **P** — pause, **R** — fly again, **Enter / click** — start

## The mission

Eight rings hang over the valley at set altitudes — fly through each one for +100 points and +4% fuel. Miss one and it is gone. After the last ring, the runway waits at the far end of the valley: come in slow (under ~60 kt) and gentle, or the Kestrel breaks up. Land with fuel and time to spare for the bonus. Hit the terrain and the run is over.
